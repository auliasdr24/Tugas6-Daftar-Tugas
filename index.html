    Dokumentasi Pengembangan Aplikasi

    1. Git dan GitHub

    Git digunakan untuk mencatat dan mengelola perubahan kode selama pengembangan aplikasi. GitHub digunakan untuk menyimpan repository secara online. Dalam proyek ini digunakan branch, commit, merge, Pull Request, serta penyelesaian merge conflict.

    2. npm

    npm (Node Package Manager) digunakan untuk mengelola package dan dependency yang dibutuhkan aplikasi. Perintah npm install digunakan untuk memasang dependency, npm run dev untuk menjalankan aplikasi, dan npm run build untuk membuat versi production.

    3. TypeScript

    TypeScript digunakan untuk mengembangkan logika aplikasi dengan sistem tipe data. Penerapannya meliputi primitive types, array, interface, type alias, union type, dan generic function.

    4. Vite

    Vite digunakan sebagai development server dan build tool. Vite memudahkan proses pengembangan melalui server lokal serta membantu menyiapkan file aplikasi untuk production.

    5. Environment Variables

    Environment variables digunakan untuk menyimpan konfigurasi aplikasi. Proyek ini menggunakan VITE_APP_NAME untuk nama aplikasi dan VITE_APP_VERSION untuk versi aplikasi. File .env digunakan untuk konfigurasi lokal, sedangkan .env.example menjadi contoh konfigurasi.

    6. Compiler, Transpiler, dan Bundler

    Compiler adalah alat yang memeriksa dan menerjemahkan kode sumber. Dalam proyek ini, TypeScript Compiler (tsc) memeriksa tipe data dan menghasilkan JavaScript.

    Transpiler mengubah kode dari satu bahasa atau versi bahasa ke bentuk lain. TypeScript ditranspilasi menjadi JavaScript agar dapat dijalankan oleh browser.

    Bundler menggabungkan dan memproses file aplikasi beserta dependency menjadi file yang siap digunakan. Proses build Vite menghasilkan file production di dalam folder dist.
